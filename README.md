# Post App

A full-stack post application built with React, Express.js,
MongoDB, Mongoose, Multer, and ImageKit.

## Features

- Create image posts
- Add captions
- Upload images using ImageKit
- View all posts in a feed
- Delete posts
- Responsive UI
- REST API for post management

## Tech Stack

### Frontend
- React
- React Router
- Axios
- React Icons
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- ImageKit
